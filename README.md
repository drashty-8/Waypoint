# Waypoint

*A phone-based visual recall app that tags photos with BLE room location and lets you find things later with a natural-language search.*

## Branching

Branch off `main` using one of these prefixes based on the type of change:
- `feature/short-description` for new functionality
- `fix/short-description` for bug fixes
- `docs/short-description` for documentation-only changes
- `chore/short-description` for setup, config, dependency updates

Open a pull request to merge back into `main`.
